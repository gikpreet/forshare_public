= 연습 6: 연관된 영역을 위한 인스턴스 테스트

이제, 서버가 제대로 확인되는지 확인하기 위해 인스턴스에 SSH로 한 번 더 접속해야 합니다. 아래 절차에 따릅니다.

1. Cloud Shell에서, 아래 명령을 실행하여 인스턴스에 접속합니다.
+
----
$ ssh -i <private_ssh_key> opc@<public ip>
----

2. server01.zone-b.local을 찾습니다.
+
----
host server01.zone-b.local;
----
+
아래와 같은 응답을 보게 됩니다:
+
----
server01.zone-b.local has address 172.16.0.123
----

Resolver 변경에 몇 분 정도 소요될 수 있습니다. 기다리지 않으려면 인스턴스를 재부팅하십시오.
