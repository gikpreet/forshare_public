= 연습 8: OKE 클러스터에 배포된 리소스 삭제

여기에서는 OKE 클러스터에 배포된 리소스를 삭제합니다.

아래 절차에 따릅니다.

1. 아래 명령을 실행하여 클러스터에 생성된 샘플 웹 애플리케이션과 다른 리소스들을 삭제합니다.
+
----
$ kubectl delete -f HelloWorld-lb.yaml -n ns-user01
----
+
실행 결과는 아래와 같습니다.
+
----
deployment.apps "helloworld-deployment-user01" deleted
service "helloworld-service-user01" deleted
----

2. 아래 명령을 실행하여 삭제를 확인합니다.
+
----
$ kubectl get all -n ns-user01
----
+
실행 결과는 아래와 같습니다.
+
----
No resources found in us-user01 namespace.
----
