= 연습 4. SSH 키 생성
:toc:
:sectnums:

이 연습에서는 컴퓨트 인스턴스에서 인증을 위해 사용할 SSH 키를 생성합니다. 아래 절차에 따릅니다.

1. 터미널을 실행합니다.
2. 터미널에서 아래 명령을 실행하여 홈 디렉토리로 이동합니다.
* macOS / Linux
+
----
cd ~
----
* Windows
+
----
cd %userprofile%
----

3. .ssh 디렉토리를 확인합니다. 없다면 아래 명령을 실행하여 .ssh 디렉토리를 생성합니다.
+
----
mkdir .ssh
----

4. 아래 명령을 실행하여 .ssh 디렉토리로 이동합니다.
+
----
cd ./.ssh
----

5. 아래 명령을 실행하여 SSH 키를 생성합니다. Key의 이름은 _oci_instances_key 입니다.
+
----
ssh-keygen -t rsa -b 4096 -f oci_instances_key
----
* **Enter passpharse (empty for no passphrase):** 프롬프트에서 아무것도 입력하지 않고 Enter 키를 누릅니다.
* **Enter same passpharse again:** 프롬프트에서 프롬프트에서 아무것도 입력하지 않고 Enter 키를 누릅니다.

6. 생성된 키를 확인합니다.
+
----
oci_instances_key
oci_instances_key.pub
----

7. 개인 키 권한을 제한합니다.
* macOS / Linux에서는 아래 명령을 실행합니다.
+
----
cmhod 600 oci_instances_key
----
* windows에서는 명령 프롬프트에서 아래 명령을 실행합니다.
+
----
icacls oci_instances_key /inheritance:r
icacls oci_instances_key /grant:r "%username%":F
----
