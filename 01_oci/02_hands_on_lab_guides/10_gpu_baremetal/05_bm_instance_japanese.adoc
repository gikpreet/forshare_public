= 演習4. GPU BMインスタンスの作成
:sectnums:

この演習では、Oracle公式GitHubで提供されているイメージを使用して、GPU BMインスタンスを作成します。以下の手順に従ってください。

== Oracle公式GitHubでイメージとPARを検索

ここでは、Oracle公式GitHubでPAR（Pre-Authenticated Request）として提供されているカスタム・イメージを検索します。以下の手順に従ってください。

1. Webブラウザで新しいウィンドウを開き、以下のWebサイトにアクセスします。
+
https://github.com/oracle-quickstart/oci-hpc-oke/blob/main/docs/worker-node-images.md?utm_source=chatgpt.com[Images to Use for Worker Nodes]

2. 作成するBMのシェイプに対応するイメージを探します。以下の例は、BM.GPU.B4.8シェイプと互換性のあるUbuntu 22.04イメージです。
+
image:./images/05/image01.png[]
+
NOTE: 本書を作成している2026年7月27日時点で、JSONリスト（https://raw.githubusercontent.com/oracle-quickstart/oci-hpc-oke/main/docs/worker-node-images.json）は7月14日に更新されています。

== PAR URLからカスタム・イメージをインポートする

ローカルPCにイメージをダウンロードする必要はありません。OCIがOracle Object StorageのPAR URLを読み取り、ユーザーのテナンシにカスタム・イメージを作成するように設定できます。以下の手順に従ってください。

1. 左上のハンバーガーメニュー（≡）をクリックし、**Compute**をクリックします。
+
image:./images/05/image02.png[]

2. **Compute**ページで、**Custom Images**をクリックします。
+
image:./images/05/image03.png[]

3. **Custom Images**ページで、**Compartment**に `tasks` (演習2で作成したコンパートメント)を指定します。
+
image:./images/05/image04.png[]

4. **Import Images**ボタンをクリックします。
+
image:./images/05/image05.png[]

5. **Import Images**ページで、以下のように情報を入力します。
* **Create In compartment**: `tasks (演習2で作成したコンパートメント)`
* **Name**: `Ubuntu-22.04-<BM Shape Name>-<image_update_date>`
* **Operating System**: `Ubuntu`

6. **Import from an Object Storage URL**オプションを選択します。
7. **Images to Use for Worker Node**sページを開いているWebブラウザのウィンドウ(またはタブ)に移動し、BMと互換性のあるイメージのリンクを探します。リンクを右クリックして、**リンクのアドレスをコピーを**クリックします。
+
image:./images/05/image06.png[]

8. コピーしたリンクアドレスを**Object Storage URL**に貼り付けます。
9. Image TypeにOCIを指定します。
+
image:./images/05/image07.png[]

10. 右下の**Import Image**ボタンをクリックします。
11. イメージのインポートが開始されます。インポートが完了すると、ステータスが**Available**に変わります。
+
image:./images/05/image08.png[]

12. インポートが完了したら、右側のメニューで**Custom Image**をクリックし、インポートしたカスタム・イメージを確認します。
+
image:./images/05/image09.png[]

== BMインスタンスの作成

1. 左上のハンバーガーメニュー（≡）をクリックし、Computeをクリックします。
+
2. **Compute**ページで、**Instances**をクリックします。
+
image:./images/05/image10.png[]

3. **Create Instance**ボタンをクリックします。
+
image:./images/05/image11.png[]

4. **Create compute instance**ページで、以下のとおり情報を入力します。なお、この演習ではAshburnリージョンを使用します。
* **Name**: `bm-gpu-instance`
* **Create in compartment**: `tasks (演習2で作成したコンパートメント)`
* **Placement**: 該当するBMリソースが存在するADを選択します。
+
image:./images/05/image12.png[]

5. **Image and shape**セクションの**Image**で、**Change**ボタンをクリックします。
+
image:./images/05/image13.png[]

6. **Select an image**ページで、**My Images**をクリックします。
+
image:./images/05/image14.png[]

7. 下にスクロールし、**Custom images**オプションを選択した後、イメージ一覧からインポート済みのイメージを選択します。
+
image:./images/05/image15.png[]

8. **Shape**セクションで、**Change Shape**ボタンをクリックします。
+
image:./images/05/image16.png[]

9. **Browse all shapes**ページで、**Bare Metal machine**を選択します。
10. **Oracle and Nvidia Terms of Use**の通知ウィンドウで、**Confirm**ボタンをクリックします。
+
image:./images/05/image17.png[]

11. Shape一覧から、作成するShapeを選択し、**Select shape**ボタンをクリックします。
+
image:./images/05/image18.png[]

12. 選択したShapeに変更されていることを確認します。
+
image:./images/05/image19.png[]

13. 右下の**Next**ボタンをクリックします。

14. **Security**セクションで情報を確認し、**Next**ボタンをクリックします。
+
image:./images/05/image20.png[]

15. **Networking**で、以下のように設定します。
* Primary VNIC
** Primary network
*** **Select existing virtual cloud network**: 選択
*** **Virtual cloud network compartment**: `tasks (演習2で作成したコンパートメント)`
*** **Virtual cloud network**: `ai_infra_vcn (演習3で作成したVCN)`
** Subnet
*** **Select existing subnet**: 選択
*** **Virtual cloud network compartment**: `tasks (演習2で作成したコンパートメント)`
*** **Virtual cloud network**: `public subnet-ai-infra_vcn (regional)`

+
image:./images/05/image21.png[width=650]

* Private IPv4 address assignment
** **Subnet IPv4 address**: `Automatically assign private IPv4 address` (デフォルト値)
* Public IPv4 address assignment
** **デフォルト値のままにします。**

+
image:./images/05/image22.png[width=650]

* Add SSH keys
** **Upload public key file (.pub)**: 選択
** **Drop a file or select one**をクリックし、演習4で作成した公開鍵ファイル（oci_instances_key.pub）を選択します。

+
image:./images/05/image23.png[width=650]

16. 右下の**Next**ボタンをクリックします。

17. **Boot volume**ではデフォルト値のままにし、右下の**Next**ボタンをクリックします。
+
image:./images/05/image24.png[width=650]

18. **Review**ページで情報を確認し、右下の**Create**ボタンをクリックします。
19. コンピュート・インスタンスの作成が開始されます。作成が完了するまで待ちます。
20. 作成が完了します。
