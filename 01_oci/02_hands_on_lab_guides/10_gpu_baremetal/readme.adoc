= Lab 10: GPU Baremetal 인스턴스를 생성하고 테스트

이 연습에서는 OCI 콘솔을 사용하여 GPU Baremetal 인스턴스를 생성하고 생성된 인스턴스에 접속하여 환경을 테스트하는 작업을 수행합니다.

OCI에서 GPU Baremetal 인스턴스를 생성하는 과정은 일반 VM 생성과 유사하지만, **용량 할당(Service Limit) 요청 및 전용 네트워크(RDMA/Cluster Network) 구성**과 같은 사전 작업이 필수적으로 동반됩니다. 

이 연습에서는, RDMA와 같은 전용 네트워크의 구성이 없는 단일 GPU 노드를 생성하고 테스트하는 것을 연습합니다.

이 연습에서는 다음과 같은 작업들을 수행합니다:

1. 서비스 한도를 확인합니다.
2. VCN 및 프라이빗 서브넷 준비
3. Bare Netal 인스턴스를 생성하고 액세스
4. 구성 환경 확인
