= 연습 3: Docker 이미지를 컨테이너로 실행

Docker 이미지는 Docker가 컨테이너로 실행하려는 애플리케이션을 담고 있습니다.여기에서는 빌드한 Docker 이미지를 컨테이너로 실행합니다.

아래 절차에 따릅니다.

1. 아래 명령을 사용하여 `docker run' 명령을 사용하여 생성된 이미지로 부터 컨테이너를 실행합니다.
+
----
$ docker run -d --name webapp-<userID> -p 8080:80/tcp oci_sample_webapp_<userID>:<tag>
----
+
명령의 실행 예는 아래와 같습니다:
+
----
$ docker run -d --name webapp-user01 -p 8080:80/tcp oci_sample_webapp_user01:1.0
----
파라미터는 아래와 같습니다.

* `-d`: 컨테이너를 백그라운드로 실행하고 `CONTAINER_ID` 를 출력합니다.
* `--name`: 컨테이너의 이름을 지정합니다.
* `-p`: 컨테이너의 80번 포트를 호스트의 8080번 포트로 포워딩합니다.

+
NOTE: 명령을 실행하면 컨테이너가 백그라운드로 실행되며, `CONTAINER_ID` 를 출력합니다.

2. 아래 명령을 실행하여 실행중인 컨테이너를 확인합니다.
+
----
$ docker ps
----
+
결과는 아래와 같습니다:
+
----
CONTAINER ID  IMAGE                                   COMMAND               CREATED        STATUS        PORTS                 NAMES
0ca5b5629805  localhost/oci_sample_webapp_user01:1.0  nginx -g daemon o...  7 seconds ago  Up 7 seconds  0.0.0.0:8080->80/tcp  webapp-user01
----

NOTE: 빌드한 Docker 이미지를 이 연습을 마칠때까지 삭제하지 마십시오. 이 이미지는 이어지는 연습에서 사용됩니다.
