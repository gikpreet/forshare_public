= Compute Instance 생성
:sectnums:

이 연습에서는 Oracle Cloud Infrastructure에서 Ubuntu 운영체제 컴퓨트 인스턴스를 생성하고 외부에서 액세스하는 환경을 만드는 것을 실습합니다. 이 연습은 아래 절차로 진행됩니다.

1. 컴파트먼트(Compartment) 생성
2. 가상 클라우드 네트워크(Virtual Cloud Network - VCN) 생성
3. SSH 키 생성
4. 컴퓨트 인스턴스(Compute Instance 생성)
5. 외부에서 SSH를 사용해 접속

아래 절차를 따릅니다.

== SSH 키 생성

이 연습에서는 컴퓨트 인스턴스에서 인증을 위해 사용할 SSH 키를 생성합니다. 아래 절차에 따릅니다.

1. 터미널을 실행합니다.
2. 터미널에서 아래 명령을 실행하여 홈 디렉토리로 이동합니다.
* macOS / Linux
+
----
cd ~
----
* Windows
+
----
cd %userprofile%
----

3. .ssh 디렉토리를 확인합니다. 없다면 아래 명령을 실행하여 .ssh 디렉토리를 생성합니다.
+
----
mkdir .ssh
----

4. 아래 명령을 실행하여 .ssh 디렉토리로 이동합니다.
+
----
cd ./.ssh
----

5. 아래 명령을 실행하여 SSH 키를 생성합니다. Key의 이름은 _oci_instances_key 입니다.
+
----
ssh-keygen -t rsa -b 4096 -f oci_instances_key
----
* **Enter passpharse (empty for no passphrase):** 프롬프트에서 아무것도 입력하지 않고 Enter 키를 누릅니다.
* **Enter same passpharse again:** 프롬프트에서 프롬프트에서 아무것도 입력하지 않고 Enter 키를 누릅니다.

6. 생성된 키를 확인합니다.
+
----
oci_instances_key
oci_instances_key.pub
----

7. 개인 키 권한을 제한합니다.
* macOS / Linux에서는 아래 명령을 실행합니다.
+
----
cmhod 600 oci_instances_key
----
* windows에서는 명령 프롬프트에서 아래 명령을 실행합니다.
+
----
icacls oci_instances_key /inheritance:r
icacls oci_instances_key /grant:r "%username%":F
----

== 실습 리소스 삭제

여기에서는 실습에서 생성한 모든 리소스를 삭제합니다. 

* Oracle Cloud Infrastructure에서 더 이상 사용하지 않는 리소스를 삭제하는 것은 비용 낭비를 막고 인프라를 깔끔하게 유지하기 위한 필수 작업입니다. OCI는 엔터프라이즈 환경에 맞추어 설계되었기 때문에, 리소스 간의 종속성과 물리적 삭제 정책이 명확하게 구분되어 있습니다.
* OCI의 가장 중요한 규칙은 "자식 리소스나 연결된 리소스가 남아있으면 리소스를 삭제할 수 없다"는 점입니다.
** **예시(VCN 삭제)**: 가장 네트워크(VCN)를 삭제하고 싶다면, 그 VCN 안에 만들어진 컴퓨트 인스턴스, 로드 밸런서, 서브넷 등을 먼저 전부 삭제해야만 최종적으로 VCN을 삭제할 수 있습니다.
** **강제 삭제 불가**: 부모 리소스를 다 지운다고 해서 하위 리소스들이 자동으로 일괄 삭제(Cascade Delete) 되지 않는 경우가 많습니다. 인프라를 처음부터 하나씩 역순으로 걷어내야 합니다.

OCI에서 리소스 삭제에 대한 개념은 link:../00_concepts/01_delete_oci.adoc[Oracle Cloud Infrastructure에서 리소스 삭제]를 참조하십시오.

이 실습에서 생성한 모든 리소스를 완전히 정리하려면 아래 순서대로 리소스를 삭제해야 합니다.

1. Compute Instance Terminate
2. VCN 삭제
3.. 컴파트먼트 삭제

아래 절차에 따릅니다.

=== Compute Instance와 Boot Volume 삭제

여기에서는 Compute Instance와 Boot Volume을 함께 삭제합니다. 절차에 따릅니다.

1. OCI 콘솔의 왼쪽 위에 있는 햄버거 메뉴를 클릭합니다.
2. **Compute**를 클릭하고 **Instances**를 클릭합니다.
3. 연습에서 생성한 `ubuntu-lab-vm` 인스턴스의 마지막 컬럼에 있는 **...** 메뉴를 클릭하고 **Terminate** 를 클릭합니다.
+
image:./images/image40.png[width=600]

4. **Terminate instance** 경고 상자에서 **Permanetly delete attached boot volume** 체크박스를 선택하고 **Terminate Instance** 버튼을 클릭합니다.
+
image:./images/image41.png[width=450]

5. 삭제가 진행됩니다.
6. 삭제가 완료되면 인스턴스의 상태가 `Terminated` 로 변경됩니다. 이 인스턴스는 수시간이 지나면 사라집니다.

=== VCN 삭제

여기에서는 VCN을 삭제합니다. 아래 절차에 따릅니다.

1. OCI 콘솔의 왼쪽 위에 있는 햄버거 메뉴를 클릭합니다.
2. **Networking**을 클릭하고 **Virtual cloud networks**를 클릭합니다.
3. 연습에서 생성한 `instances_vcn` VCN의 마지막 컬럼에 있는 **...** 메뉴를 클릭하고 **Delete** 를 클릭합니다.
+
image:./images/image42.png[width=600]
4. **Delete Virtual Cloud Network** 페비이에서, 오른쪽 아래의 **Scan** 버튼을 클릭합니다.
+
image:./images/image43.png[width=500]
5. 스캔이 완료되면, 오른쪽 아래의 **Delete All** 버튼을 클릭합니다.
+
image:./images/image44.png[width=500]
6. VCN이 삭제됩니다.

=== 컴파트먼트 삭제

1. OCI 콘솔의 왼쪽 위에 있는 햄버거 메뉴를 클릭합니다.
2. **Identity & Security**을 클릭하고 **Compartments**를 클릭합니다.
3. 연습에서 생성한 `compute_instances` VCN의 마지막 컬럼에 있는 **...** 메뉴를 클릭하고 **Delete** 를 클릭합니다.
+
image:./images/image45.png[width=600]
4. **Delete compartment** 경고 상자에서 **Delete** 버튼을 클릭합니다.
5. 삭제가 진행됩니다. (컴파트먼트의 상태가 `Deleting` 으로 변경됩니다.)
6. 삭제가 완료되면 컴파트먼트의 상태가 `Deleted` 로 변경됩니다. 이 컴파트먼트는 수시간이 지나면 사라집니다.
